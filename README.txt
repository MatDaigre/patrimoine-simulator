PATRIMOINE SIMULATOR — VERSION MOBILE/PWA

Pour jouer sur iPhone, cette version doit être publiée sur une adresse HTTPS.

Une fois publiée :
1. Ouvrir l'adresse dans Safari.
2. Appuyer sur Partager.
3. Choisir « Sur l'écran d'accueil ».
4. Lancer Patrimoine Simulator depuis son icône.

La sauvegarde reste locale à l'appareil/navigateur. Utiliser Exporter pour la transférer.
